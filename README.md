🌸 MARAFLORESDEBACH - Plataforma de Gestión
Bienvenido a la plataforma web para la gestión integral de servicios de Flores de Bach y masoterapia.

🎯 ¿Qué hace esta plataforma?
Esta aplicación web permite administrar de manera eficiente todos los aspectos del negocio:

📦 Catálogo de productos (Flores de Bach, masajes, accesorios)
👥 Gestión de clientes y su información
🔐 Control de usuarios del sistema (administradores, gerentes, empleados)
📊 Panel de control para visualizar toda la información importante


👤 Tipos de Usuario
Administrador
Tiene acceso completo al sistema:

Ver, crear, modificar y eliminar productos
Gestionar usuarios del sistema
Administrar información de clientes
Acceso al panel de control completo

Cliente (Usuario final)
Acceso desde el sitio web público:

Ver catálogo de productos
Información sobre servicios
Contacto y consultas


🛍️ Funcionalidades Principales
📦 Gestión de Productos
Lo que puedes hacer:

Ver todos los productos disponibles
Agregar nuevos productos al catálogo
Editar información de productos existentes (nombre, precio, stock, descripción, imágenes)
Activar o desactivar productos
Organizar productos por categorías

Categorías disponibles:

Flores de Bach
Masajes y terapias


👥 Gestión de Clientes
Información que se administra:

Datos personales (nombre, RUT, email, teléfono)
Dirección completa (región, comuna, dirección)
Fecha de nacimiento
Estado del cliente (activo/inactivo)
Historial completo

Lo que puedes hacer:

Registrar nuevos clientes
Actualizar información de clientes existentes
Buscar clientes por email o RUT
Ver todos los clientes activos
Desactivar clientes cuando sea necesario

🔐 Gestión de Usuarios del Sistema
Control de acceso:

Crear cuentas para empleados y gerentes
Asignar roles y permisos
Activar o desactivar usuarios
Cambiar contraseñas de forma segura
Ver quién tiene acceso al sistema

📊 Panel de Control (Dashboard)
Vista general con acceso rápido a:

Resumen de productos
Lista de clientes
Usuarios activos del sistema
Accesos directos a las funciones más usadas


🔒 Seguridad

✅ Contraseñas encriptadas: Todas las contraseñas se almacenan de forma segura
✅ Control de acceso por roles: Cada usuario solo ve lo que le corresponde
✅ Protección de datos: Información de clientes protegida
✅ Validaciones: El sistema verifica que todos los datos sean correctos antes de guardarlos


💻 Tecnología Utilizada

Frontend: Interfaz moderna y fácil de usar (React)
Backend: Sistema robusto y escalable (Spring Boot)
Base de datos: Almacenamiento seguro (PostgreSQL)
Arquitectura: Sistema modular de microservicios para mejor rendimiento
